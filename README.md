## Deploy
Upload `index.html` and the entire `assets` folder to the root of your `engineering-portfolio` GitHub repository. Keep the `assets` folder name unchanged.

Your repository should look like:

```
engineering-portfolio/
  index.html
  assets/
    ace-logo.jpg
    ace-members.webp
    ace-lab.jpg
    combat-robots.jpg
    dark-knyte.jpg
    gm-internship.jpg
    megaknytes.jpg
```

GitHub Pages will continue to use the same public URL after the files are committed.
